## Current Projects

### LifeLike — *Founder & CEO*

A social platform built for the AI era, where every post is born with a visible
lifespan and only content that convinces strangers is allowed to stay.
Permanence is earned from the audience, never bought.

Flutter and Dart on Android, Firebase Cloud Functions on the server, Google
Cloud for content safety. Conceived, designed and built by me.

[Google Play →](https://play.google.com/store/apps/details?id=social.lifelike.app) · [Visit LifeLike →](https://lifelike.social) · [Repository →](https://github.com/vncarv/lifelike)

### OutflowResearch — *in development*

A financial education project about monetary erosion — the gap between nominal
growth and real purchasing power. Interactive tools supporting explanatory
material, starting with a browser-based financial calculator.

[Explore project →](https://github.com/vncarv/outflow-research)
